# Program 1 — Vector Addition

The first program implemented was vector addition using CUDA. The objective of this program was to understand the structure of a CUDA program and how GPU threads execute parallel computations.

The mathematical operation performed in this program was:

```
C[i] = A[i] + B[i]
```

Each thread computes the addition for one element of the vector.

The CUDA kernel implemented was:

```cpp
__global__ void vectorAdd(int *A, int *B, int *C, int N)
{
    int i = blockIdx.x * blockDim.x + threadIdx.x;

    if(i < N)
        C[i] = A[i] + B[i];
}
```

The important part of this kernel is the computation of the global thread index.

```
i = blockIdx.x * blockDim.x + threadIdx.x
```

This formula determines the position of the thread in the entire grid and ensures that each thread processes a unique vector element.

Host memory was allocated using dynamic allocation, and GPU memory was allocated using:

```
cudaMalloc()
```

Input vectors were transferred to GPU memory using:

```
cudaMemcpy()
```

The kernel was launched using the CUDA kernel launch syntax:

```
vectorAdd<<<blocks, threads>>>(d_A, d_B, d_C, N);
```

The number of blocks was computed to ensure that the total number of threads covers the vector size.

After kernel execution, the result vector was copied back to CPU memory using `cudaMemcpy`.

This program helped in understanding the basic CUDA workflow consisting of memory allocation, memory transfer, kernel execution, and result retrieval.

# Program 3 — Vector Addition using Unified Memory

The third program introduced unified memory in CUDA. In the previous programs, memory transfers between CPU and GPU were handled manually using `cudaMemcpy`. In this program, unified memory was used to simplify memory management.

Memory was allocated using:

```
cudaMallocManaged()
```

Example:

```cpp
cudaMallocManaged(&A, size);
```

This allocation creates memory that can be accessed by both CPU and GPU. CUDA automatically handles data migration between CPU and GPU memory when required.

The CUDA kernel used remained the same as the vector addition kernel.

```cpp
__global__ void vectorAdd(int *A, int *B, int *C, int N)
{
    int i = blockIdx.x * blockDim.x + threadIdx.x;

    if(i < N)
        C[i] = A[i] + B[i];
}
```

After launching the kernel, synchronization was required using:

```
cudaDeviceSynchronize()
```

This ensures that the GPU computation completes before the CPU accesses the result data.

This program demonstrated how unified memory simplifies CUDA programming by eliminating explicit memory copy operations between host and device.

# Program 4 — Matrix Addition

The fourth program implemented matrix addition using CUDA. This program introduced two-dimensional thread indexing, which is commonly used in matrix operations and image processing applications.

The mathematical operation performed was:

```
C[row][col] = A[row][col] + B[row][col]
```

The kernel implemented was:

```cpp
__global__ void matrixAdd(int* A, int* B, int* C, int width, int height)
{
    int row = blockIdx.y * blockDim.y + threadIdx.y;
    int col = blockIdx.x * blockDim.x + threadIdx.x;

    if(row < height && col < width)
    {
        int index = row * width + col;
        C[index] = A[index] + B[index];
    }
}
```

This program introduced the use of two-dimensional grids and thread blocks.

The thread coordinates were calculated using:

```
row = blockIdx.y * blockDim.y + threadIdx.y
col = blockIdx.x * blockDim.x + threadIdx.x
```

Each thread processes one matrix element based on its row and column position.

The kernel launch used a two-dimensional configuration:

```
dim3 threads(16,16);
dim3 blocks((width+15)/16, (height+15)/16);
```

This mapping allows threads to naturally correspond to matrix coordinates, which is an important design pattern used in many GPU algorithms such as matrix multiplication and convolution operations.

Through this program, the concept of mapping two-dimensional data structures to CUDA thread grids was practiced.
